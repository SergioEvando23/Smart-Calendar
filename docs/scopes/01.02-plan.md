# Plano — Escopo 01.02: Bootstrap Web, API e persistência

## Fonte

Especificação fornecida em “Escopo 01.02 — Bootstrap Web, API e persistência”.

## Objetivo

Inicializar a aplicação Web em React/TypeScript, a API em Node.js/Fastify e a persistência PostgreSQL via Prisma, sem implementar funcionalidades de negócio.

## Arquitetura e contratos

- Web consulta a API por cliente HTTP tipado e não acessa o banco diretamente.
- API expõe `GET /health/live` e `GET /health/ready`.
- Readiness verifica PostgreSQL; Ollama não participa da prontidão.
- Docker expõe somente a Web e mantém API/PostgreSQL na rede interna.

## Critérios e validação

- Lint, typecheck, testes, build e geração do Prisma Client foram executados com sucesso.
- A validação em Docker e a conexão a PostgreSQL real aguardam Docker Compose v2 disponível.

## Riscos e dependências

- A branch `develop` não existe; a branch atual foi derivada do estado disponível do repositório.
- A plataforma Mobile não foi definida neste escopo e permanece fora da implementação.
